# QA Portfolio – E-Commerce (LUMA)

Project: E-Commerce LUMA – Manual Test Cases
Role: Quality Assurance (Manual Tester / QA Engineer)
Tools: Google Sheets, Chrome DevTools, Test Plan Design, Test Case Design, Bugs Report, Manual Testing

---

## 📌 Scope Pengujian
Fitur yang diuji dalam proyek ini:
- 📝 **Sign Up** – Pendaftaran akun baru
- 🔑 **Login** – Autentikasi user
- 🔄 **Forgot Password** – Reset password user
- 🛒 **Add to Cart** – Menambahkan item ke keranjang
- 🛒 **Checkout** – Bersedia untuk membeli item
- 🔑 **Payment** – Membayar item yang di checkout

Pengujian berfokus pada perilaku fungsional dan alur yang penting bagi bisnis, bukan pada validasi tampilan antarmuka pengguna (UI) secara kosmetik.
---

## 🎯 Test Objectives
- Memvalidasi keberhasilan pembuatan akun menggunakan data yang valid
- Memverifikasi perilaku sistem ketika data yang tidak valid atau tidak lengkap dikirimkan
- Memastikan pesan kesalahan muncul dengan benar untuk kasus uji negatif
  
Test artifacts meliputi:
- Test Plan
- Test Cases
- Final Report

## 🔍 Key Findings & Insights
- Proses pembayaran dan checkout diperlakukan sebagai fitur terpisah berdasarkan perilaku sistem.
- Metode pembayaran di LUMA dipilih secara default, sehingga skenario "pembayaran kosong" menjadi tidak valid.
- Hasil pengujian manual konsisten untuk alur end-to-end.


## 🧠 Key Learnings
- Understanding input validation & negative testing
- Creating structured manual test cases
- Documenting expected & actual results
